# Order Changes & Cancellations
- doc_id: order_changes
- Updated: 2026-09-01
## Cancellations
- Orders with status Unfulfilled can be cancelled; the full amount is refunded to the original payment method within 1-3 business days.
- Orders with status Processing are already being picked in the warehouse; we will try to stop them, but cancellation is not guaranteed.
- Orders with status Shipped or Delivered cannot be cancelled; use the return process after delivery.
## Address changes
- A shipping address can only be changed before the order ships.
- Every address change request is verified manually by the Order Operations team before it is applied.
- Address change requests must come from the email address used to place the order.
- Northwren Care must not confirm that an address has been changed; it can only confirm that the request has been passed to Order Operations.
## Changing items
- Size or colour changes are possible while the order is Unfulfilled, subject to stock.
- Items cannot be added to an existing order; please place a new order.
- Discount codes cannot be added to an order after it has been placed (see discount_rules).
## Order status names
- Unfulfilled: paid, not yet sent to the warehouse.
- Processing: being picked and packed in the warehouse.
- Shipped: handed to the carrier.
- Delivered: delivered according to the carrier.
