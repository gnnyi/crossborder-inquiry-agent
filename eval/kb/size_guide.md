# Size Guide
- doc_id: size_guide
- Updated: 2026-06-01
- All measurements are body measurements, not garment measurements.
- Each product page also has a fit note; when the fit note and this guide differ, follow the fit note.
## Size conversion (tops, dresses, skirts, pants, knitwear, outerwear)
- XS = US 0-2 = UK 4-6 = EU 32-34 = AU 4-6.
- S = US 4-6 = UK 8-10 = EU 36-38 = AU 8-10.
- M = US 8-10 = UK 12-14 = EU 40-42 = AU 12-14.
- L = US 12-14 = UK 16-18 = EU 44-46 = AU 16-18.
- XL = US 16 = UK 20 = EU 48 = AU 20.
- XXL = US 18 = UK 22 = EU 50 = AU 22 (selected styles only).
## Body measurements in cm (bust / waist / hip)
- XS: 80-83 / 61-64 / 86-89.
- S: 84-88 / 65-69 / 90-94.
- M: 89-94 / 70-75 / 95-100.
- L: 95-101 / 76-82 / 101-107.
- XL: 102-108 / 83-89 / 108-114.
- XXL: 109-115 / 90-96 / 115-121.
## Body measurements in inches (bust / waist / hip)
- XS: 31.5-32.5 / 24-25 / 34-35.
- S: 33-34.5 / 25.5-27 / 35.5-37.
- M: 35-37 / 27.5-29.5 / 37.5-39.5.
- L: 37.5-40 / 30-32.5 / 40-42.
- XL: 40-42.5 / 32.5-35 / 42.5-45.
- XXL: 43-45 / 35.5-38 / 45.5-47.5.
## Jeans (Sloane Straight Jeans, sized by waist)
- Jeans sizes 24-32 match waist measurement in inches: size 27 fits a 27 in (69 cm) waist.
- Size 24 = XS, 25-26 = S, 27-28 = M, 29-30 = L, 31-32 = XL (approximate).
## Belts
- Linden Leather Belt S/M fits waist 64-76 cm; M/L fits waist 76-90 cm.
## Between sizes
- If you are between two sizes, choose the larger size for fitted styles and the smaller size for oversized styles.
- Northwren Care can recommend a size from the measurements you share, but cannot guarantee fit.
